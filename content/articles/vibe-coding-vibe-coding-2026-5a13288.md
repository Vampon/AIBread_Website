## 🎬 从一条推开始

2025 年 2 月，OpenAI 联合创始人、AI 圈里那个画风很赛博朋克的大佬 Andrej Karpathy，在 X 上发了一条不长的推：

> **"有一种新的编程方式，我称之为 'vibe coding'，你完全沉浸在氛围里，拥抱指数级增长，甚至忘掉代码的存在……我不是真的在编程，我只是看东西、说东西、运行东西、复制粘贴东西，而且大部分时候都能跑。"**

这条推被转疯了。一个月后，"Vibe Coding"这个词进了维基百科。半年后，《纽约时报》刊了篇文章——《AI 和 vibecoding 让我做出了自己的软件》。再过半年，2026 年的今天，连 Verdict 都在预测：**Vibe Coding 会在 2026 年成为主流**。

但绝大多数人——包括很多自称"用过 Cursor"的人——其实没搞懂这件事到底意味着什么。

他们以为 Vibe Coding 就是"AI 帮我补全代码"，是"GitHub Copilot 的升级版"，是"自动写注释"。

不是。完全不是。

**这事的本质，是一个角色对调：你不再是写代码的人，你是"指挥写代码的人"的人。**

---

## 🆚 先把它和"AI 补全"分清楚

很多人混了两件事，咱们先掰开。

**一个精妙的类比：**

| | AI 代码补全 | Vibe Coding |
|---|---|---|
| 你在干啥 | 写一句代码，AI 帮你接半句 | 你说"做一个能发周报的网站"，AI 自己规划、自己写、自己跑、自己改 |
| 角色定位 | 你是司机，AI 是导航 | 你是导演，AI 是整个剧组 |
| 必须懂代码吗 | 必须，不然你接不住它给的 | 不一定，你要懂"想清楚要什么" |
| 出活的颗粒度 | 一行 / 一个函数 | 一个功能 / 一整个项目 |

听明白了吗？

GitHub Copilot 那种"AI 补全"，你是主角，AI 是辅助。你眼睛盯着代码，手不离键盘，AI 在你旁边小声提醒"这里可以这么写"。

而 Vibe Coding 是反过来的——**AI 是主角，你是甲方+监工**。你眼睛甚至可以不看代码（Karpathy 原话："忘掉代码的存在"），你只看效果："这个按钮颜色不对""这里登录流程有 bug""加个导出 PDF 的功能"。

AI 听完，自己去翻代码、自己改、自己重启服务，然后告诉你"好了，您再看看"。

这是两种完全不同的工作模式。Copilot 那种用法已经存在五年了，Vibe Coding 是真正的新东西。

## 🎯 那它到底跟 no-code 有啥区别？

肯定有人要问：你说的"说话就出软件"，这不就是 Bolt、Lovable 这些 no-code 工具吗？

**这是另一个常被搞混的边界。**

我用一个比喻把它们分开：

- **No-code 工具**（Bolt、Lovable、v0）：像**搭乐高**。模块都给你做好了——登录是一块、表单是一块、支付是一块。你拼起来就行。**它生成的"代码"你基本看不到，也改不了底层结构。**

- **Vibe Coding**：是**真在写代码**——只是你不动手，AI 动手。生成的是真实的 React/Python/TypeScript 项目文件，你可以打开看、可以改、可以部署到任何地方。

举个具体例子：

你想做一个"自动把会议录音转成结构化纪要"的工具。

- 用 **Lovable**：能做出一个能用的网页版，登录、上传、显示纪要都有。但你想加一个"自动同步到飞书"——抱歉，模块库里没有，你就卡死了。
- 用 **Claude Code（Vibe Coding）**：AI 给你写一个完整的 Python 后端 + React 前端项目。你说要同步飞书，它去查飞书 API 文档，写调用代码，跑通。**没有任何"模块限制"**——因为它写的就是真代码。

**No-code 的天花板是平台给你的；Vibe Coding 的天花板是你的想象力和 AI 的能力。**

当然，no-code 的优势是快、是傻瓜——做 MVP 验证想法非常合适。后面第 02 篇我们会专门讲怎么选工具。

## 🤔 那为什么是 2026 年？

这事我得讲两句历史。

"AI 写代码"这个梦不是新的——2021 年 Copilot 发布的时候大家就在喊。但很长一段时间，**它就是个梦**。

为什么？因为之前的模型有三个硬伤：

1. **写不长**——超过 200 行就开始胡说，变量名都对不上
2. **改不动**——给它一个有 bug 的项目，它要么大改特改、要么完全看不懂
3. **没记忆**——你跟它说过的规则，下一轮对话就忘了

所以那时候 Vibe Coding 顶多算"高级写作业辅助"，做不了真项目。

转折是 **2024 年底到 2025 年**。Claude 3.5 Sonnet 出来的时候，圈里人第一次发现："咦，这玩意儿能改我两万行的项目了？" 然后 Anthropic 推出 **Claude Code**（一个跑在终端里的 AI Agent），OpenAI 推出 **Codex CLI**，模型本身又一路升到 Opus 4.5 / GPT-5.1-codex——

**三个硬伤同时被解决了**：

- 写得长：现在一次输出几千行无压力，做完整功能没问题
- 改得动：可以读懂一个几万行的代码库，定位 bug 比初级工程师还快
- 有记忆：通过 `AGENTS.md`、`memory-bank/` 这套机制，AI 能"记住"你的项目（后面第 04 篇会专门讲）

到了 **2026 年 6 月**——也就是现在——Claude Opus 4.5、GPT-5.1-codex (xhigh)、Gemini 3.0 Pro 这三个第一梯队的编程模型，在真实项目上的成功率已经过了"可用"门槛。

> **关键判断：Vibe Coding 不再是极客玩具，它是普通人 2026 年应该具备的一项基础能力。**

就像 2010 年你不会用智能手机会被淘汰、2020 年你不会用 ChatGPT 会被淘汰——2026 年你不会用 AI 写出自己想要的小工具，就是另一次淘汰。

## 💡 谁最该会一点 Vibe Coding？

讲完原理，咱聊聊实用的——**这事到底跟哪些人有关？**

我的答案可能跟你想的不一样：**最该学的不是程序员，是产品经理、独立创业者、运营、设计师。**

为什么？

**对程序员来说**，Vibe Coding 是效率提升。本来一天写完，现在半天写完。爽，但不是革命。

**对非程序员来说**，Vibe Coding 是**从 0 到 1 的能力解锁**。

举几个真实场景：

- **产品经理**：以前你想验证一个交互假设，得排期、找前端、等两周——现在你自己用 Cursor 半天搓个 demo，下午就能拿去用户面前测
- **运营**：以前你想做个"自动从公众号后台拉数据生成日报"的小工具，得求开发同学——现在跟 Claude Code 说一下午，工具上线了
- **独立创业者**：以前一个 idea 要 3 个月 + 一个技术合伙人才能验证——现在一个周末就能跑出 MVP
- **设计师**：以前你画的原型给到开发，做出来跟你想的差 30%——现在你用 v0 一边对话一边调，所见即所得

**一个精妙的类比：**

Vibe Coding 之于知识工作者，就像**手机之于摄影**。

以前拍张能看的照片，得有单反、得懂光圈快门、得会后期。摄影是"专业人士"的事。手机出来之后，每个人都能拍——而且拍得不差。

这没让摄影师失业。但它让**"用图片表达想法"这件事，从专业能力变成了人人都该有的能力**。

Vibe Coding 也一样。它不会让程序员失业（高级工程师反而更值钱了，因为大架构师还是不可替代）。但它会让**"用软件解决自己的问题"**这件事，从"码农才会的事"变成"现代人都该会一点的事"。

## ⚠️ 但有几个误区，得先打掉

讲到这儿肯定有人开始热血沸腾——"我下午就装 Claude Code！"

打住。Vibe Coding 的坑很多，提前给你打三个预防针：

**误区一：以为 AI 啥都能写**

不能。涉及钱、医疗、安全的代码，AI 写的你必须每行看过。Belitsoft 2026 年 10 月报道过一个事——亚马逊一次大规模宕机，事后查就是 GenAI 辅助修改的代码触发的。所以：**小工具、个人项目、内部用——放心用。涉及生产环境、用户数据——人审。**

**误区二：以为不用学任何东西**

要学。Vibe Coding 不是让你"不学编程"，是让你**学的重点变了**——

以前要学：怎么写 for 循环、怎么用 React Hook、怎么配 Webpack
现在要学：怎么把需求讲清楚、怎么拆模块、怎么 debug、怎么读懂 AI 写的代码大致结构

这些在传统编程里反而是"高阶能力"——现在变成了入门必备。

**误区三：以为不需要规划**

最大的坑。Vibe Coding 圈里有句话：**"凡是上来不规划直接干的，最后都得推倒重来。"**

后面第 03 篇会专门讲规划——这是整个系列最重要的一篇。

## 🎤 最后说点真心话

我不是来卖课的，也不是要把 Vibe Coding 吹成银弹。

我自己用了大半年，翻过的车、踩过的坑、半夜对着屏幕骂街的次数——比一般人多。

但同时，我也见证了一件实实在在的事：**我和我身边的几个朋友，做出了以前不可能做出的东西。**

- 一个完全不懂代码的朋友，用三个周末做了一个给自己用的"读书笔记自动整理工具"，现在已经在小范围卖了
- 一个产品经理朋友，用一周时间复刻了她之前提了半年都排不上期的内部工具，老板看完直接拍板
- 我自己做了一个公众号文章配图自动生成器，已经省了几百个小时

这些事在 2024 年都不可能。在 2026 年的今天，**只要你愿意花一两个月认真学一下**，全都能做。

这就是 Vibe Coding 真正的意义——

**它把"造软件"这件事，从少数人的特权，变回了所有人都能掌握的工具。**
