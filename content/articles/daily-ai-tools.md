刷过的 AI 榜单、AI 推荐合集，没有 100 也有 50。但**真到了每天会打开的**，就那么几个。

这篇不堆量。我列我自己每天真打开的 7 个 AI 工具，每个工具配**一个最值得抄的用法**。

## 1. ChatGPT —— 主力对话

**用法**：日常问题、写作初稿、代码片段、辅助阅读、查资料。

**最值得抄**：用 **Voice Mode 通勤**。开车 / 走路 / 坐地铁时，按住麦克风跟 ChatGPT 聊。聊行业问题、聊读书感想、让它帮你梳理一个困扰你的问题。**比听播客高效 3 倍**——它会针对你的疑问展开，不是单方面输出。

**不爽的点**：免费版限频、模型时灵时不灵。

## 2. Claude —— 长文档主力

**用法**：处理长文档、读论文、批量改文章、深度对话。

**最值得抄**：用 **Project 功能**。把你正在做的某个事情（比如装修选材、做毕业论文、找工作）相关的所有文件都拖进同一个 Project——合同 PDF、装修预算 Excel、设计图 JPG、笔记 Markdown——然后在这个 Project 里对话。Claude 一直"记得"这些资料，不用每次重发。

**不爽的点**：国内访问不稳定，需要稳定网络。

> 推荐组合：**ChatGPT + Claude 双开**。ChatGPT 日常对话，Claude 专门处理长文档和重要任务。互相补，年费总共一千多。

## 3. NotebookLM —— 资料消化器

**用法**：把一堆 PDF / 网页 / 视频字幕喂进去，跟它对话学。

**最值得抄**：让它把资料**变成一段双人播客**。NotebookLM 有个奇怪但好用的功能：把你上传的资料生成一段 8–15 分钟的英文双人对话播客。你通勤路上听一段，相当于"被人喂养"了那份资料。

**不爽的点**：免费但有点慢、中文播客功能还不太成熟。

## 4. Cursor —— 代码主力（如果你写代码的话）

**用法**：日常开发，边写边问 AI。

**最值得抄**：用 **Cmd+K 行内改**。选中一段代码，按 Cmd+K，输入"把这里改成 async/await"或者"加一行 try-catch"——它就在原地改，不需要复制粘贴。这一个快捷键比所有的"AI 解释代码"功能都常用。

**不爽的点**：$20/月对偶尔写代码的人有点贵。

> 程序员对照阅读：[Claude Code 上手](/blog/claude-code-guide)

## 5. 即梦 / Midjourney —— 出图

**用法**：公众号配图、PPT 配图、朋友圈配图。

**最值得抄**：**别用大段提示词**。直接说"水彩风格 / 一张面包 / 暖色调 / 极简"四件套就完事。复杂提示词会让 AI 困惑，简单粗暴反而出图好。

**国内推荐用即梦**（字节出的，免费、出图快、中文 prompt 友好）。**英文 prompt 玩家**继续 Midjourney。

## 6. 飞书妙记 / Otter —— 实时转录

**用法**：开会、采访、上课，AI 实时转写文字 + 自动总结。

**最值得抄**：开完会**直接让它出"行动事项"**——飞书妙记和 Otter 都能一键总结成一个待办清单（谁负责啥、几号截止）。**会议纪要从此不用人写**。每周省下 2–3 小时。

## 7. Perplexity —— 联网研究

**用法**：需要查资料、做小研究、看跨多源观点时用它，不用 ChatGPT 联网搜索。

**最值得抄**：研究一个不熟悉的话题（比如"现在 AI 公司主要的盈利模式都有哪些"），让 Perplexity 出一份带 8–10 个引用源的回答。**它的引用是真的能跳转到原文的**——你可以一边看 AI 摘要、一边校验它有没有瞎说。

**为啥不用 ChatGPT 联网**：ChatGPT 联网像个临时工，Perplexity 是把搜索作为产品核心做的。**深度研究 Perplexity 完胜**。

## 8. 一个组合工作流：周报 + 行业情报

把上面 7 个工具组合起来，每周省一两个晚上的事。我每周一早上的流程：

```
1. [飞书妙记] 自动总结上周所有会议 → 拿到一份会议要点清单
2. [Claude Project] 把会议要点 + 自己的工作笔记一起丢进 Project
   → 让 Claude 梳理 "上周做了什么 / 这周要做什么"
3. [Perplexity] 让它给我整理 "本周 AI 行业 5 件大事"
4. [ChatGPT] 把上面 3 个材料合并 → 生成一份给老板的周报
5. [即梦] 给周报配个暖色调封面图（如果是发到团队 wiki 里）
```

**全程自己只做 30 分钟的检查 + 删改**。换之前是周日晚上写两小时。

## 9. 我没列进来的，和我为啥不用

公允地说一下我**试过但没留下来**的：

- **Devin / Manus**：完全自主 Agent，目前还不够稳。
- **Sora / 可灵**：视频生成，对我用处不大，玩具属性强。
- **Runway / Pika**：同上，视频用得少。
- **Chatbot 套壳类（一万种）**：核心都是封装别家 API，没必要。
- **AI PPT (Gamma 等)**：好用但我做 PPT 频率太低，没必要单独订阅。

> **筛选原则**：每周打开少于 1 次的工具，**不要订阅**。AI 工具订阅费会快速失控。我的总订阅约 $50/月，比咖啡少一些。
