我帮过几十个朋友"调教"过他们的 AI 助手。每次问题都一样：

> "我用 ChatGPT 它给的回答好水啊，跟你给我看的差好多。"

我看一眼他们的 prompt，基本是这样：

- "帮我写个文案"
- "看一下这个简历"
- "这段话改一下"

**这不是 AI 不行，是你给它的信息太少**。

今天教你一个公式——**4 件套提示词框架**：身份 + 任务 + 背景 + 格式。学会这个，你的 AI 立刻从"实习生"升级成"专业顾问"。

## 第 1 件套：身份

**告诉 AI 它是谁**——这决定了它用什么口吻、什么深度回答你。

❌ 反例：

```
帮我改一下这段文字
```

✅ 加身份：

```
你是一位严谨的图书编辑，请帮我改这段文字
```

加之前 AI 给你的可能是"这段文字写得不错，建议……"。加之后 AI 立刻进入**编辑模式**：揪标点、改语序、删冗词。

**身份要具体**。不要写"专业人士"、"老师"——太泛。要写"在儿童出版社工作 10 年的资深编辑"、"教高中历史的特级教师"。越具体，AI 越入戏。

## 第 2 件套：任务

**明确告诉 AI 你要它做什么**。动词要具体。

❌ 反例：

```
看一下这个简历
```

"看一下"是啥意思？看完夸两句？挑刺？打分？AI 只能瞎猜。

✅ 写任务：

```
请挑出 3 处可以让 HR 眼前一亮的亮点，并指出 5 个需要改进的地方
```

注意几个细节：

- **数量定下来**：3 处亮点、5 处改进——AI 不会少给也不会废话凑
- **方向给出来**：让 HR 眼前一亮的亮点（不是普通亮点）
- **角度给出来**：从 HR 视角而不是从你自己视角

## 第 3 件套：背景

**把 AI 当一个刚入职的实习生——它什么都不知道**。你要把背景信息告诉它。

❌ 反例：

```
帮我写个发言稿
```

✅ 给背景：

```
我是技术总监，下周要在公司年会上做 3 分钟开场，
听众是 200 人的非技术同事，氛围要轻松，
公司今年业务上有大调整，但不要直接讲业务，要讲文化
```

背景信息越多，AI 越能写出"非通用、量身定做"的回答。

**新手最容易漏的就是这一件**。你脑子里默认的前提（你的身份、场合、听众、限制），AI 全都不知道。

## 第 4 件套：格式

**指定输出格式**。不指定，AI 默认会写一大段连续的话。

❌ 反例：

```
总结一下这份会议纪要
```

✅ 给格式：

```
用 markdown 表格输出，三列：
- 议题
- 结论
- 待办（包含责任人和截止时间）
```

或者：

```
分成 3 个段落：
1. TL;DR（30 字以内）
2. 关键决策（不超过 5 条）
3. 风险提醒
```

**格式越具体，AI 越听话**。这是减少返工的最大杀器。

## 4 件套完整范例

把上面 4 件套拼一起，看看一个真正的好 prompt 长啥样：

```
你是擅长写朋友圈文案的小红书博主。
帮我写本周六晚的同学聚会邀请。

背景：
- 8 个老同学，10 年没见
- 地点是 KTV
- 氛围要俏皮但不油腻
- 群里大多数是已婚有娃的中年人

请输出 2 个版本，每个 60 字以内，
带 2-3 个表情符号但不滥用。
```

你把这段发给 ChatGPT 或 Claude，回来的文案直接能用，几乎不用改。

## 6 个高频场景的现成模板

我把日常用得最多的 6 个场景写成模板，直接抄走改一改就能用。

### 1. 改简历

```
你是一位招聘 [岗位] 的资深 HR，看过上千份简历。
请帮我审视下面这份简历，目标是冲 [公司] 的 [岗位]。

[粘贴简历]

请给出：
1. 3 个最大的亮点（具体说明为什么打动人）
2. 5 个需要改的地方（每条给修改建议）
3. 一句话总结这份简历当前的水平（直说，别客气）
```

### 2. 写邮件

```
你是一位有礼貌但不卑不亢的职场沟通顾问。
请帮我写一封邮件给 [对象]，目的是 [目的]。

背景：
- [关系]
- [上下文]
- [我的诉求]

要求：
- 中文，正文 200 字以内
- 开头不要"你好",直接进入正题
- 结尾给一个明确的 next step
```

### 3. 总结长文 / PDF

```
你是擅长信息提炼的研究员。
请用以下结构总结这份文档：

1. TL;DR（50 字以内）
2. 3 个核心观点（每条 1-2 句话）
3. 我应该记住的 3 个数据 / 事实
4. 与我相关的 2 条行动建议（我是 [身份]）
```

### 4. 学一个新概念

```
你是擅长把复杂概念讲给小学生的科普作家。
请用一个生活类比解释 [概念] 是什么。

要求：
- 200 字以内
- 用一个具体的生活场景做类比
- 最后一句话给一个判断对错的快速记忆点
```

### 5. 做计划

```
你是擅长拆解目标的项目经理。
我想 [目标]，但卡在 [障碍]。

请帮我做一份 [时间] 内的执行计划：
1. 拆成不超过 5 个阶段
2. 每个阶段给一个可量化的产出
3. 每个阶段标记最大的风险点
```

### 6. 做选择 / 拍板

```
你是擅长帮人理清思路的决策顾问。
我面前有 [N] 个选择：[列出选项]。
我的目标是 [目标]，约束是 [约束]。

请帮我：
1. 列出每个选项的 2 个核心利弊
2. 推荐一个，并给出 3 条最有说服力的理由
3. 推荐方案最大的风险是什么，怎么对冲
```

## 一个进阶 trick：让 AI 反问你

如果你不知道怎么写 prompt，你可以让 AI 主动来问：

```
我想 [目标]，但我不知道怎么准确描述需求。
请你像专业顾问一样反问我 5 个问题，
帮我把需求理清楚，然后再帮我做。
```

这一招叫**反向 prompt**。你不知道要啥的时候，让 AI 帮你想清楚要啥——这本身也是 AI 的强项。

## 最后

**多花 30 秒写 prompt，能省你 5 分钟改 AI 的回答**。这是高 ROI 的事。

把 4 件套抄在便签上贴电脑边，写每个 prompt 之前看一眼：身份说了吗？任务清楚吗？背景给了吗？格式定了吗？

三周以后，你会发现自己已经不需要看便签了。
