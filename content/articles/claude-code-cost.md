新人最常的两个问题:

1. **Claude Code 是不是免费的?**
2. **我每天用一小时,得交多少钱?**

答:**不免费**——它是 Claude API 的客户端,你聊天就是在烧 token。但有几个机制让它**比想象的便宜很多**。

## 1. 三种 token,三种单价

Claude API 把 token 分成三类:

| 类型 | 是什么 | 单价(Opus 4.7,$/百万 token) |
|------|--------|---------|
| **Input(新)** | 第一次进入对话的内容 | $15 |
| **Cache hit** | 之前发过、被缓存命中 | **$1.5(打了 1 折)** |
| **Output** | 模型生成的回复 | $75 |

数字会随模型变,但**比例关系是稳的**:

- Output 比 Input 贵 5 倍
- Cache hit 比 Input 便宜 10 倍

## 2. 一次「读 README」具体花多少

模拟一个简单对话:

```
你:看一下 README 第一行
Claude:[Read README.md] → "# 我的小工具"
```

Token 大概:

- **Input**: ~3,500(系统 prompt 1,800 + CLAUDE.md 800 + 工具菜单 600 + 你的话 50 + Read 结果 250)
- **Output**: ~80(它的回复)

按上面单价:

```
input cost  = 3500 / 1_000_000 * $15 = $0.0525
output cost = 80   / 1_000_000 * $75 = $0.0060
total ≈ $0.06(约 4 毛人民币)
```

听起来还好。但**第二轮第三轮**呢?

## 3. 没有缓存就完蛋

每一轮对话,Claude API 是**无状态**的——你必须把**整段历史**重发一次。

第 5 轮对话时,你可能已经累积:

```
- 系统 prompt    1,800
- CLAUDE.md      800
- 工具菜单       600
- 4 轮历史 + 工具结果 ~12,000
- 这一轮新输入   200
─────────────────────
总 input ≈ 15,400 tokens
```

**每一轮都按 input 单价算钱?那每聊一句几毛钱**——一小时聊几十轮,吓人。

这就是 **prompt cache** 出场的地方。

## 4. Prompt cache 是怎么省 90% 的

Claude API 会自动把**最近发过的内容**缓存 5 分钟。下一轮如果**前缀完全一样**,缓存的部分**按 1 折计费**。

具体到 Claude Code:

- 系统 prompt 永远在前面 → **永久命中**
- CLAUDE.md 永远固定 → **永久命中**
- 工具菜单基本不变 → **永久命中**
- 对话历史**顺序保留** → 老的几轮 **命中**
- 这一轮新的输入 + 工具结果 → 新计费

第 5 轮的真实账单:

```
- cache hit  : 14,200 → $0.0213
- fresh input: 1,200  → $0.0180
- output     : 80     → $0.0060
─────────────────────────────
total ≈ $0.045
```

**比没有缓存便宜约 70%**。长会话效果更明显。

## 5. 看自己花了多少:/cost

随时在终端敲:

```
> /cost
```

输出大概像:

```
本次会话:
  input tokens:     34,520
    └ cache hit:    24,800 (71%)
    └ fresh:         9,720
  output tokens:     5,400
─────────────────────────────
  TOTAL:           $0.582
```

`/cost` 让钱**从抽象变具体**——你会发现:

- **大部分钱花在 output 上**(单价高 5 倍)
- **缓存命中 70%+ 是正常**水平
- **/compact 后命中率会暂时降**(摘要替换了原对话,缓存失效)

## 6. 实战省钱套路

按效果排序:

1. **让 Claude 简短回答**——output 单价高,啰嗦最贵。CLAUDE.md 加一句「除非要求详细,默认 1-3 句话」。
2. **不滥用 /compact**——除非真接近上限。压缩本身要花 output token,且压缩后短期缓存失效。
3. **大任务派 [子代理](/blog/claude-subagent)**——它的上下文不污染主对话,主对话缓存继续命中。
4. **不要无谓地 read 大文件**——Read 把整文件塞 input,大文件 token 几千起跳,read 错了浪费两次(读一次 + 后续每轮带它)。
5. **卡住就 /clear**——重开比 /compact 更彻底,也更便宜(没有摘要 output 费用)。

## 7. 大概一个月花多少?

参考点(轻度个人开发者,每天 1-2 小时):

- 大部分对话 $0.5-2
- 一天 5-10 次对话 → **$5-15/天**
- **一个月 $150-450**

省钱模式:

- **Claude Pro/Max 订阅**:Anthropic 包月,**算下来比按 token 便宜不少**——专门为重度 API 用户设计的。
- **公司报销**:打工人不用想了,扔到工时里。

## 8. 一句话总结

> Claude Code 不便宜,但 prompt cache + 简短输出能让它**便宜不止一半**。

理解 token 怎么算,你就**会用了** Claude Code——不是「能不能用」,是「**用得起多久**」。
