你跟 ChatGPT 聊天——你问一句，它答一句。对话结束，它什么都不会做。

但你跟 Claude Code 说话——你说"帮我搭一个博客"，它自己创建文件、写代码、装依赖、跑起来给你看。

**后者就是 AI Agent——一个不只"说话"，而是"做事"的 AI。**

---

## 📖 一句话定义

**AI Agent（智能体）是一个能自主规划、使用工具、执行多步任务、根据结果调整策略的 AI 系统。** 它不只是回答问题，而是"完成任务"。

---

## 🧠 一个精妙的类比：聊天机器人 vs 私人助理

| | 聊天机器人（Chatbot） | AI Agent |
|---|---|---|
| 类比 | 图书馆咨询台 | 私人助理 |
| 你能让它干什么 | 回答问题 | 完成任务 |
| 它能记住多久 | 当前对话 | 长期记忆 + 上下文 |
| 它能用工具吗 | 不能 | 能——搜索、写文件、调 API |
| 它能自主决策吗 | 不能，一问一答 | 能——规划步骤、遇到问题自己调整 |
| 例子 | ChatGPT（基础版） | Claude Code、AutoGPT、Devin |

**聊天机器人是"脑子"——能思考，能表达。**
**AI Agent 是"脑子 + 手 + 工具"——能思考，能行动。**

```
聊天机器人：
  你："明天天气怎么样？"
  AI："抱歉，我无法查询实时信息。"
  
AI Agent：
  你："明天天气怎么样？"
  AI Agent：
    1. 调用天气 API（Tool）
    2. 获取结果："明天北京晴，25°C"
    3. 回复你："明天北京晴天，25°C，适合出门！"
    4. （可选）帮你把天气信息发到邮箱
```

## 🔧 AI Agent 的四个核心能力

任何一个 Agent，必须具备这四项能力：

| 能力 | 做什么 | 类比 |
|------|--------|------|
| **🧠 推理（Reasoning）** | 理解任务、分析问题、做决策 | 大脑 |
| **📋 规划（Planning）** | 把大任务拆成小步骤 | 项目经理 |
| **🔧 工具使用（Tool Use）** | 调 API、读文件、搜网页、执行代码 | 双手 |
| **💾 记忆（Memory）** | 记住上下文、记住之前的经验 | 笔记本 |

**一个精妙的类比：做一道复杂的菜**

- **推理**：理解"宫保鸡丁"是什么，需要什么食材
- **规划**：第一步切鸡肉，第二步准备调料，第三步炒，第四步装盘
- **工具使用**：用刀切肉、用锅炒菜、用计时器控制火候
- **记忆**：记住"上次花生放多了，这次少放点"

**没有推理的 Agent = 乱做一通的厨师。**
**没有工具的 Agent = 只有想法没有手的厨师。**
**没有规划的 Agent = 做到一半不知道下一步干嘛的厨师。**
**没有记忆的 Agent = 每次都从零开始的厨师。**

## 🔄 Agent 的工作循环

Agent 不是"一次调用就完事"，而是一个循环：

```
┌─────────────────────────────────────────┐
│                                           │
│  ① 接收任务                               │
│     "帮我分析这份财报并写一份报告"           │
│           ↓                               │
│  ② 思考 & 规划                            │
│     "我需要：读文件 → 提取数据 → 分析 → 写作" │
│           ↓                               │
│  ③ 选择工具 & 执行                        │
│     调用 read_file()，读取财报 PDF          │
│           ↓                               │
│  ④ 观察结果                               │
│     "读到了 20 页内容，数据在 5-15 页"       │
│           ↓                               │
│  ⑤ 判断：完成了吗？                        │
│     没完成 → 回到②，继续下一步              │
│     完成了 → ⑥                            │
│           ↓                               │
│  ⑥ 返回最终结果                           │
│                                           │
└─────────────────────────────────────────┘
```

**这个循环叫"ReAct"（Reasoning + Acting，推理+行动）。** 几乎所有现代 Agent 都基于这个模式。

## 🎯 你现在就在用 Agent

| Agent | 你用它做什么 |
|-------|------------|
| **Claude Code** | 写代码、调试、部署、重构 |
| **Cursor** | AI 辅助编程 |
| **GitHub Copilot** | 代码补全 + Agent 模式 |
| **ChatGPT + Plugins** | 联网搜索、数据分析 |
| **Perplexity** | AI 搜索（搜索 + 总结） |
| **Devin** | 全自主编程 Agent |

**AI 编程工具本身就是最成功的 Agent 应用。** 你学 Agent，其实就是在学"怎么更好地使用和开发 AI 编程工具"。

---

## 🧠 总结

- **AI Agent = 不只是聊天，而是"干活"的 AI——有脑子、有手、能规划、有记忆**
- 四个核心能力：推理、规划、工具使用、记忆
- 工作循环：思考 → 行动 → 观察 → 判断 → 循环或结束
- Claude Code、Cursor、Copilot 本身就是 Agent
- 学 Agent = 学怎么让 AI 从"会说话"变成"会做事"
